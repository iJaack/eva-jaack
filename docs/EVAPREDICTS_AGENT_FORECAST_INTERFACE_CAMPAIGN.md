# @evapredicts Agent Forecast Interface Campaign

## Objective

Turn Eva Protocol's MCP/agent surface into a measurable campaign destination for agent builders without publishing externally before approval.

## Campaign Hypothesis

Agent builders will respond better to "forecast agents need an interface for receipts" than to broad AI-prediction claims. They already believe agents can generate forecasts. The sharper pain is whether the agent read the right sources, respected the publish boundary, preserved revision triggers, and left an inspectable author/runtime trail.

## Target Audience

- agent builders turning prediction-market data into public forecast outputs
- prediction-market operators who want agent distribution without unverifiable screenshots
- crypto analysts using agents to draft, counter, or revise market theses
- protocol teams comparing AI forecast UX by source quality and permission boundaries
